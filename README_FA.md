# مدیریت تاکتیکی

بسته پروژه شامل نسخه وب بازی و بک‌اند اولیه برای امکانات آنلاین است.

## ساختار
- `index.html` — نسخه اصلاح‌شده بازی وب، شامل اتصال API، ورود/ثبت‌نام آنلاین، ذخیره ابری و نمایش لیگ آنلاین.
- `backend/` — سرور Node.js + PostgreSQL.

## امکانات آنلاین آماده در کد
حساب کاربری، ذخیره ابری، پروفایل باشگاه، صف لیگ‌های ۱۰ تیمی، برنامه رفت‌وبرگشت ۱۸ هفته‌ای، جدول لیگ، چت عمومی و پیام خصوصی.

## راه‌اندازی
راهنمای کامل فارسی در `backend/README_FA.md` است. برای انتشار عمومی به مخزن GitHub، دیتابیس PostgreSQL (مثلاً Neon) و میزبانی بک‌اند (مثلاً Render) نیاز است. فایل `render.yaml` تنظیمات اولیه سرویس Render را آماده می‌کند؛ مقدار `DATABASE_URL` را هنگام ساخت سرویس وارد کن. فایل‌های این بسته به‌تنهایی سرور را روی اینترنت منتشر نمی‌کنند.

## وضعیت مهم
موتور مسابقه سمت سرور و ضدتقلب نتیجه هنوز تکمیل نشده‌اند؛ به همین دلیل API نتیجه مسابقه فعلاً عمداً غیرفعال است. اتحادها، جام‌ها، بازی دوستانه و بازار نقل‌وانتقالات نیز هنوز به‌صورت کامل آنلاین نیستند.
