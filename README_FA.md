# بک‌اند بازی «مدیریت تاکتیکی»

این پوشه شامل API مبتنی بر Node.js، Express و PostgreSQL است.

## امکانات آماده در این نسخه
- ثبت‌نام و ورود با شماره، نام کاربری و رمز عبور؛ رمزها با bcrypt هش می‌شوند.
- احراز هویت با JWT.
- ذخیره و بازیابی ابری وضعیت بازی.
- ذخیره پروفایل باشگاه و نام مربی روی سرور.
- لیگ‌های چندگانه ۱۰ تیمی با ۱۸ هفته و ۹۰ مسابقه در هر لیگ.
- صف انتظار تا تکمیل ۱۰ حساب واقعی؛ هیچ تیم ساختگی ایجاد نمی‌شود.
- جدول لیگ و برنامه مسابقات.
- صعود و سقوط دو تیم بالای جدول و دو تیم پایین جدول پس از تکمیل فصل.
- چت عمومی و ارسال/دریافت پیام خصوصی.
- مسیر سلامت `/health` که اتصال دیتابیس را نیز بررسی می‌کند.

## محدودیت‌هایی که هنوز باید تکمیل شوند
- موتور شبیه‌سازی مسابقه هنوز سمت سرور اجرا نمی‌شود؛ بنابراین API عمداً نتیجه ارسالی مرورگر را قبول نمی‌کند و مسیر `/league/result` پاسخ `501` می‌دهد. این کار جلوی ثبت نتیجه ساختگی را می‌گیرد.
- اتحادها، جام‌ها، دوستانه‌ها، نقل‌وانتقالات و بازار قرضی هنوز به‌صورت کامل سمت سرور پیاده‌سازی نشده‌اند.
- برای انتشار عمومی باید محدودسازی درخواست‌ها، تأیید شماره/بازیابی حساب، پایش خطا و سیاست حریم خصوصی نیز تکمیل شوند.

## راه‌اندازی محلی
نیازمندی: Node.js نسخه ۲۰ یا بالاتر و یک دیتابیس PostgreSQL.

1. در همین پوشه ترمینال باز کن.
2. دستور `npm install` را اجرا کن.
3. فایل `.env.example` را با نام `.env` کپی کن.
4. مقدار `DATABASE_URL` را با نشانی دیتابیس و مقدار `JWT_SECRET` را با یک رشته تصادفی طولانی و محرمانه جایگزین کن (حداقل ۳۲ نویسه).
5. دستور `npm start` را اجرا کن.
6. مسیر `http://localhost:3000/health` باید JSON با `status: ok` و `database: connected` برگرداند.

## انتشار روی Render و Neon

### ۱) دیتابیس Neon
- یک پروژه PostgreSQL بساز.
- نشانی اتصال را از بخش Connection Details کپی کن؛ نشانی باید SSL داشته باشد (معمولاً `?sslmode=require`).
- این نشانی را فقط در متغیر محرمانه `DATABASE_URL` در Render قرار بده؛ آن را در GitHub یا داخل HTML نگذار.

### ۲) انتشار بک‌اند روی Render
- یک Web Service جدید بساز و مخزن GitHub پروژه را متصل کن.
- Root Directory: `backend`
- Build Command: `npm install`
- Start Command: `npm start`
- Environment Variables:
  - `DATABASE_URL`: نشانی Neon
  - `JWT_SECRET`: رشته تصادفی محرمانه با حداقل ۳۲ نویسه
  - `CORS_ORIGIN`: در زمان آزمایش `*`؛ پیش از انتشار عمومی، دامنه دقیق سایت بازی
- پس از Deploy، نشانی سرویس باید HTTPS باشد.

### ۳) اتصال بازی
- فایل `index.html` را باز کن.
- وارد پروفایل > اتصال سرور آنلاین شو.
- فقط ریشه دامنه Render را وارد کن؛ `/api` یا `/health` به انتهای آن اضافه نکن.
- «آزمایش اتصال» را بزن. پاسخ سالم باید اتصال دیتابیس را هم تأیید کند.
- سپس حساب آنلاین بساز یا وارد شو.
- برای انتقال پیشرفت قبلی، «انتقال ذخیره فعلی به سرور» را بزن. پس از آن ذخیره خودکار ابری فعال می‌شود.

## مسیرهای اصلی API
- `GET /health`
- `POST /auth/register`
- `POST /auth/login`
- `GET /me`
- `POST /me/club`
- `GET /me/save` و `POST /me/save`
- `POST /league/join` و `GET /league/me`
- `GET /chat/messages` و `POST /chat/messages`
- `GET /private-messages` و `POST /private-messages`
- `POST /league/result` فعلاً عمداً غیرفعال است تا موتور مسابقه سمت سرور آماده شود.

**نکته:** کدها و تنظیمات آماده انتشار هستند، اما تا وقتی مخزن GitHub، دیتابیس Neon و سرویس Render ساخته و متصل نشوند، سرور عمومی آنلاین وجود ندارد.
